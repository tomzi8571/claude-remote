# claude-remote
Coding via claude remote 

## Chat with Myself

A React (Vite) app in `chat/` where you message yourself; messages are kept in the browser's
localStorage. `.github/workflows/deploy.yml` builds it and deploys it to GitHub Pages on every
push to `main`: https://tomzi8571.github.io/claude-remote/

Run locally: `cd chat && npm install && npm run dev`.
